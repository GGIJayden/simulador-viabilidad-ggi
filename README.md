# Simulador de viabilidad robótica · GGI Robotic

Herramienta web para que una empresa evalúe si le conviene automatizar una tarea con un brazo robótico.

1. **Personal:** cada puesto con su sueldo, turno, asignación familiar, horas extra y otros costos; régimen laboral general, pequeña empresa o microempresa.
2. **Producto y robot:** carga útil requerida = (peso del producto × productos por ciclo + peso del gripper) × (1 + tolerancia), y alcance requerido según el pallet o la distancia de trabajo. Propone robots FANUC reacondicionados que cumplen ambos requisitos.
3. **Inversión de la celda:** robot, herramienta, periféricos, seguridad, control, ingeniería, puesta en marcha, instalación y contingencia.
4. **Resultado:** ahorro neto, payback, VAN y TIR después de impuestos, según la metodología de viabilidad de GGI (noviembre 2026).

Todos los valores son referenciales. La cotización definitiva requiere el levantamiento en planta.

Es una sola página estática (`index.html`), publicada con GitHub Pages.
